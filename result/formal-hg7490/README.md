# hg7490 · C7552 形式化验证证据

- TLC 1.7.4 对 TLA+ 流程抽象模型执行穷举状态检查。实际结果为 213 个生成状态、141 个不同状态、搜索队列为空、无不变量违规。注入的 Canary 不变量触发反例。
- Z3 4.12.2 检查 C7552 已归档证据编码的 516 条事实，正例 SAT，注入矛盾的负例 UNSAT。SAT 表示已输入的约束可同时满足；它不证明记录没有遗漏或被输入转换隐藏。
- 模型检查对象是抽象协议和不变量，数据约束对象是归档证据。三路电压与时间网格的数值一致性是另一项测试。以上不证明 NGSPICE 数值算法在任意电路上正确。
- 这里的两类形式化工具均实际在 hg7490 执行，独立服务器复现未执行。该证据针对已归档数据，不是新解压性能批次的验收凭证。

安装 Java 11、TLA+ 1.7.4 的 tla2tools.jar，以及 Python 和 z3-solver==4.12.2.0。然后执行：

~~~bash
TLC_JAR=/absolute/path/to/tla2tools.jar PYTHON=python3 bash run.sh
~~~

inputs/ 保存约束及其来源事实，logs/ 保存原始工具输出和 TLC 退出码。工具来自官方 TLA+ Release 和 PyPI；本包记录版本及 JAR 指纹。
