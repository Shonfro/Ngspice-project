# 文档索引

所有可执行实验代码统一位于 `code/`：原有核心框架在 `code/core/`，动态库实验在 `code/dynamic_library/`。

- `experiments/solver.md`：求解器实验方法与历史结果。
- `experiments/bolt.md`：BOLT 实验方法与历史结果。
- `experiments/numa.md`：NUMA 实验方法与历史结果。
- `experiments/dynamic-library.md`：动态库实验设计、验证和结果位置。
- `analysis/dynamic-library-optimization-report.md`：动态库独立分析记录。

企业报告不复制到本工程；工程内文档只记录本项目实际保留的数据和复核方法。
